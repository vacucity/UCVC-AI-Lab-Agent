# 深度经营分析报告

## 一、趋势洞察

客流处于温和上行通道。未来7日平均客流3186人、14日3220人、30日3294人，逐级抬升；相较历史平均2934人，分别高出8.6%、9.7%、12.3%（数据包 derived.avgVsHistoryPct），上行斜率平缓而非陡增。最新实际客流3097人，较历史均值高5.6%、较中位数高6.7%，但较p95低13.0%，说明当前处于正常偏高水位，尚未触及极端峰值。

周期规律上，短期存在一次温和回调：次日（2026-06-12）预测2914人，较最新实际3097人下降5.9%（derived.nextVsLatestPct），预测区间[2758, 3070]人。7日、14日、30日三个窗口的预测最小值均为2914人，即回调低点与次日预测重合，之后重新进入上行。整体形态可概括为"短回调、中抬升"。

## 二、归因分析

本报告归因链的唯一驱动因素为历史客流走势（贡献度100%），即近期变化、周期规律与客流波动共同决定预测走向，逐条因果链如下：

- **上行链**：历史客流走势 → 近期周期规律与波动 → 预测均值逐级抬升（7日3186→30日3294）→ 30日均值较历史均值高12.3%。
- **回调链**：历史客流走势 → 近期波动 → 次日预测低于最新实际5.9% → 短期收入承压，但区间下限2758人仍处历史中位数2902人附近，回调幅度有限。
- **峰值链**：历史客流走势 → 峰值预测未超限 → 30日峰值4145人对应承载率34.5%（日承载上限12000人），7日峰值3771人对应31.4%、14日峰值3852人对应32.1%（derived.peakLoadRatePct）；历史最大承载率仅30.7%，超载天数与接近承载天数均为0，安全边际充足。
- **可信度链**：历史客流走势 → 模型学习近期变化与周期规律 → 验证期8天MAE 156.42、RMSE 173.32、MAPE 5.1%，误差较小，支撑上述判断。

## 三、关键发现

1. **上行是"均值抬升"而非"峰值失控"**：30日峰值4145人较7日峰值3771人高9.9%（derived.peak30VsPeak7Pct），但承载率仅从31.4%升至34.5%，远低于上限，增长以均值稳步抬升为主。
2. **短期回调有明确边界**：次日预测区间[2758, 3070]人，下限2758人接近历史中位数2902人，说明回调属正常波动而非趋势反转。
3. **当前水位健康**：最新实际3097人较p95低13.0%，历史无超载记录（overCapacityDays=0、nearCapacityDays=0），运营压力可控。
4. **数据基础可靠**：覆盖2026-05-01至2026-06-11共42天，缺失0天、截断0天，趋势与归因结论可信。

## 四、风险与机会

- **风险（低）** ：次日预测下降5.9%，短期收入可能小幅承压；但区间下限接近历史中位数，幅度有限。
- **风险（中）** ：30日预测峰值4145人虽未超承载上限，但高于历史p95（3559人），峰值日局部时段可能出现拥挤，需提前管理。
- **机会**：30日均值较历史均值高12.3%，上行趋势明确；短期回调窗口是开展营销、拉动的天然时机。

## 五、行动建议

1. **峰值日资源前置**：当30日预测峰值达到4145人（数据包预测峰值）时，提前增派现场引导人员、开放备用通道，将峰值日承载率控制在34.5%以内。责任人为运营主管，监控指标为当日实际承载率。
2. **回调窗口营销**：当次日预测值2914人低于最新实际3097人达5.9%（触发条件：次日预测值低于最新实际5%以上）时，启动限时优惠或主题活动，目标为对冲回调、使当日客流不低于预测区间上限3070人。需同步明确营销预算与投放渠道，活动后以当日实际客流对比预测值评估效果。
3. **模型精度监控**：以验证期MAPE 5.1%为基线，每周复核一次预测误差（MAE 156.42、RMSE 173.32）；当MAPE超过6%时由数据负责人触发模型重训，并记录重训前后误差对比，确保预测准确性可追溯。
